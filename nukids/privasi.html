Kebijakan Privasi NuKids

Terakhir diperbarui: 25 November 2026 · Berlaku untuk aplikasi NuKids (Android)

Ringkasan singkat. NuKids adalah dompet digital untuk murid sekolah. Aplikasi ini menyimpan kunci dompet di HP pengguna saja, mencatat nama dan email hanya saat pendaftaran mandiri, mengirim notifikasi koin masuk dan pengumuman sekolah, dan tidak menampilkan iklan, tidak memakai analitik pihak ketiga, dan tidak menjual data pengguna.

1. Siapa kami

NuKids dikembangkan oleh Nusanian sebagai dompet NUX untuk sekolah. Dompet berjalan di atas LNBits dan jaringan Lightning Nusacoin (lnd-nux). Setiap sekolah menjalankan server sekolahnya sendiri (LNSchool) — sekolah itulah yang mengoperasikan pendaftaran murid dan pembayaran di lingkungan sekolah tersebut.

Pertanyaan tentang kebijakan ini dapat disampaikan kepada operator sekolah atau guru pendamping. Bila Nusanian menambahkan alamat email khusus privasi, alamat itu akan ditulis di sini.

2. Data yang kami kumpulkan

  • Nama dan email (pendaftaran mandiri). Saat mendaftar lewat formulir Daftar di aplikasi, nama dan email dikirim ke server sekolah untuk membuat dompet. Email dipakai sebagai pengenal peserta dan tidak boleh dipakai dua kali.
  • Kode aktivasi. Saat aktivasi lewat kode dari guru/operator, kode sekali pakai itu dikirim ke server sekolah untuk ditukar dengan kunci dompet. Kode yang sudah dipakai tidak bisa dipakai lagi.
  • Kunci dompet (inkey). Setelah aktivasi atau pendaftaran, server memberikan kunci dompet (inkey) ke HP. Kunci ini disimpan hanya di HP, di penyimpanan aman Android (Android Keystore). Kunci admin dompet (adminkey) tidak pernah keluar dari server sekolah.
  • Alamat server. Alamat server LNBits, alamat server sekolah, dan alamat webhook notifikasi yang dipakai dompet, disimpan di HP.
  • Riwayat transaksi dan saldo. Saldo, riwayat pembayaran, dan invoice (kode bayar) diambil dari server LNBits dan ditampilkan di aplikasi.
  • Token notifikasi (FCM). Untuk memberi tahu saat koin masuk, aplikasi memakai Firebase Cloud Messaging (Google). Token perangkat dikirim ke relay notifikasi kami bersama ID dompet, supaya relay tahu ke HP mana notifikasi harus dikirim.
  • Memo invoice. Bila sebuah invoice dibuat dengan memo (catatan), memo itu dapat tampil sebagai baris kedua pada notifikasi koin masuk.
  • Pengaturan aplikasi. Bahasa, tema, satuan tampil (NUX/nusan), dan preferensi layar tetap menyala — disimpan di HP saja.

3. Data yang TIDAK kami kumpulkan

  • Tidak ada iklan dan tidak ada pelacak iklan.
  • Tidak ada analitik pihak ketiga. Aplikasi tidak memakai layanan analitik atau pelaporan kerusakan (crash reporting) pihak ketiga.
  • Kamera hanya untuk memindai QR. Kamera dipakai untuk memindai kode QR saat mengirim atau menerima. Tidak ada foto atau video yang disimpan atau dikirim.
  • Tidak ada penjualan data. Data pengguna tidak dijual atau dibagikan untuk pemasaran.

4. Cara data digunakan

  • Membuat dan membuka dompet murid (aktivasi atau pendaftaran mandiri).
  • Menampilkan saldo dan riwayat, serta memproses kirim dan terima melalui server sekolah dan LNBits.
  • Mengirim notifikasi saat koin masuk (judul, jumlah, dan memo bila ada) dan pengumuman/info harian sekolah melalui topik notifikasi per sekolah.
  • Memeriksa pembaruan aplikasi (OTA) dari server pembaruan kami.

5. Pihak ketiga yang menerima data

  • Server LNBits sekolah (lnnu.taobot.org) — menyimpan dompet, saldo, dan riwayat transaksi.
  • Server sekolah (LNSchool) — memproses aktivasi, pendaftaran, dan pembayaran; menyimpan nama dan email pendaftar.
  • Relay notifikasi (nukids.taobot.org) — menerima token FCM dan ID dompet untuk mengirim notifikasi koin masuk.
  • Firebase Cloud Messaging (Google) — mengirim notifikasi ke HP. Kebijakan privasi Google berlaku untuk layanan ini.
  • Server pembaruan (catchnux.taobot.org) — menyediakan berkas pembaruan aplikasi (APK) dan catatan rilis.

6. Penyimpanan dan keamanan

  • Kunci dompet (inkey) hanya tersimpan di HP, di penyimpanan aman Android. Karena itu, bila HP hilang, saldo tidak dapat dipulihkan kecuali pengguna menyimpan cadangan inkey/adminkey dari Pengaturan lanjutan.
  • Token notifikasi disimpan di relay paling lama 90 hari.
  • Catatan pembayaran yang sudah diberitahukan disimpan di relay paling lama 24 jam, hanya untuk mencegah notifikasi ganda.
  • Data di HP terhapus saat pengguna menekan Keluar di aplikasi (kunci lokal dihapus) atau saat aplikasi dihapus dari HP. Dompet di server tetap ada dan dapat dipulihkan dengan kunci cadangan.

7. Data anak

NuKids dipakai oleh murid sekolah. Pendaftaran dilakukan oleh sekolah/operator (melalui kode aktivasi) atau oleh murid sendiri dengan nama dan email. Kami tidak meminta data lain dari anak, tidak menampilkan iklan, dan tidak mengarahkan konten pemasaran kepada anak. Orang tua atau wali dapat meminta penghapusan data anak melalui operator sekolah (lihat bagian 8).

8. Hak pengguna

Pengguna (atau orang tua/wali untuk murid) dapat:

  • Melihat saldo dan riwayat langsung di aplikasi.
  • Menghapus data di HP dengan menekan Keluar di aplikasi atau menghapus aplikasi.
  • Meminta penghapusan dompet dan data pendaftaran di server melalui operator sekolah atau melalui kontak di bagian 1.
  • Berhenti menerima notifikasi pengumuman dengan menonaktifkan notifikasi aplikasi di pengaturan HP (notifikasi koin masuk tetap mengikuti pendaftaran push di aplikasi).

9. Perubahan kebijakan ini

Bila kebijakan ini berubah, tanggal di atas diperbarui dan perubahan penting diumumkan melalui pengumuman di aplikasi. Penggunaan aplikasi sesudah perubahan berarti pengguna menyetujui kebijakan yang baru.

10. Kontak

Pertanyaan tentang kebijakan ini atau permintaan terkait data dapat disampaikan ke kontak di bagian 1.
